```

S3  bakır kaplanır             → + yeni bakır (sehpada) · eski kapak kalır

S5  zemin döşenir              → + açık zemin

S9  kapak değişir              → + yeni kapak · − yeşil kapak (istife)

   üstünde asılı, sehpa boş — yapı kaybolmaz, yer değiştirir; kaybolan yalnız eski yüz: BEDEL)
```
