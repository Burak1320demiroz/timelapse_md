# 3. ⭐ SORU SATIRI — bu hesabın asıl aleti

`HESAP_KIMLIGI` §1: burada hedef izlenme değil, **yorum kalitesi.**
Yorum kalitesini tesadüfe bırakmayan tek şey, caption'ın sorduğu sorudur.

```
SORU, MESLEĞE SORULUR — genel izleyiciye değil.

✅ İYİ (cevabı bilen biri yazmak ister)
   "Nine days a floor in winter — what would you have done differently?"
   "Single crane on a plot this tight: would you have gone mobile instead?"
   "Is the core lead of two floors what you'd run here?"

⛔ KÖTÜ (herkes yazabilir, hiçbiri ders taşımaz)
   "What do you think?"  ·  "Amazing right?"  ·  "Which one is your favourite?"

⭐ Gelen düzeltmeler doğrudan kilavuzlar/DERSLER.md ders adayıdır
   (YAYIN_PLANI §6.1). Bu satır, kanalın kendi kendini düzelten yeri.
```

     same camera, same building, same background in every shot.

# 7. 📝 DOLDURULMUŞ ÖRNEK — THE LONG SHADOW

```
It took eighteen storeys to reach the top. It took one winter to get there.

A narrow plot with zero clearance to the neighbour, so every slab, every
prop and every panel goes up on a single tower crane — the crane, not the
concrete, sets the pace. Then the cold arrives and the floor cycle stretches
from five days to nine.

14 months in 60 seconds.

Nine days a floor in winter — heat and protect, or just wait? What would you
have run on a plot this tight?

Locked-off camera. No cuts inside a shot. No narration; the only text is the closing title card.
Every frame is generated with AI. This is not a record of a real project:
no real company, no real site, no real building is depicted.

Bu video yapay zekâ ile üretilmiştir. Gerçek bir projeyi belgelemez.

#timelapse #aivideo #highrise #concrete
```
