# 1. ⚖️ KADANS — hacim değil, kadans

```
KABUL:  bu depodaki üretim akışı AĞIRDIR.
        konsept kapısı → değişmezler → merdiven → 18 prompt → prompt kapısı
        → usta kare → ters inşa (5 adım) → 6 I2V → kurgu → müzik → kapak
        → final kare kanıtı → paketleme

Bu hattı haftada birden fazla koşmak, hattın kendisini bozar. Bozulduğu ilk
yer prompt kapısıdır ("bu sefer geçmesin, sonra düzeltirim"), ikinci yer
usta kare kapısıdır. İkisi de filmin tapusu.

BAŞLANGIÇ KADANSI
   1 dikey film / hafta          (Shorts ayağı)
   1 uzun form / ay              (izlenme saati ayağı — §2)

⛔ Kadansı ARTIRMA kararı bir metrikten doğar, hevesten değil: dört hafta
   üst üste kadansı tutturduysan ve son iki filmde kapı ihlali olmadıysa
   konuşulur. Öncesinde konuşulmaz.
⚠️ Kadansı DÜŞÜRMEK bir hata değildir. YouTube'un cezalandırdığı şey
   (POLITIKA_VE_RISK §1) az yükleme değil, ŞABLON yüklemedir.
```
